3. Google Business — tuto pas à pas

But : (1) que tu aies un accès gestionnaire à leur fiche Google, (2) récupérer le Place ID, (3) créer une clé API pour que le site affiche automatiquement la note et les avis Google. Le code est déjà prêt dans le projet (api/reviews.js) : il manque seulement 2 variables dans Vercel.

Étape A — Obtenir un accès à la fiche Google (sur place, avec le propriétaire)

  1. Le propriétaire se connecte avec le compte Google qui gère la fiche, sur business.google.com.
  2. Il ouvre la fiche « Hôtel Restaurant Les Carillons » → Paramètres de l'établissement (ou « Autorisations ») → Utilisateurs / Accès → Ajouter.
  3. Il saisit ton adresse Gmail, choisit le rôle Gestionnaire (pas besoin de « Propriétaire »), puis envoie l'invitation.
  4. Tu acceptes l'invitation depuis le mail reçu ou depuis business.google.com.
Si personne ne sait qui gère la fiche : chercher l'hôtel sur Google Maps → « Gérer cet établissement » / « Revendiquer » → Google propose une validation (téléphone, courrier, vidéo). Prévoir quelques jours : à lancer dès jeudi.

Étape B — Vérifier la fiche avec eux (5 min)

  • Nom exact de la fiche :
  • Horaires à jour (hôtel / restaurant) · jours de fermeture annuelle
  • Téléphone 05 65 63 14 75 et site web https://www.lescarillons.fr
  • Catégorie principale + catégories secondaires (hôtel, restaurant, location de meublés)
  • Photos récentes · lien de réservation · description à jour
  • Qui répond aux avis ?

Étape C — Trouver le Place ID

  1. Aller sur developers.google.com/maps/documentation/places/web-service/place-id (outil « Place ID Finder »).
  2. Taper « Hôtel Restaurant Les Carillons Cransac » dans la carte et cliquer sur la bonne fiche.
  3. Noter le Place ID (commence par ChIJ…) :

Étape D — Créer la clé API Google (à faire chez toi, avec le compte Google de ton choix)

  1. Aller sur console.cloud.google.com → menu en haut → Nouveau projet → nom : « Les Carillons » → Créer.
  2. Facturation : menu ☰ → Facturation → associer une carte bancaire (Google l'exige pour activer l'API, même avec un usage gratuit). Idéalement le compte de facturation est celui de l'hôtel ; sinon le tien, à refacturer ou transférer plus tard.
  3. Menu ☰ → API et services → Bibliothèque → chercher « Places API (New) » → Activer. (Bien choisir « New », pas l'ancienne.)
  4. API et services → Identifiants → Créer des identifiants → Clé API. Copier la clé.
  5. Restreindre la clé : cliquer dessus → « Restrictions relatives aux API » → Restreindre la clé → cocher uniquement Places API (New) → Enregistrer. (Pas de restriction par site web : l'appel part du serveur Vercel, pas du navigateur.)
  6. Garde-fou budget : Facturation → Budgets et alertes → créer un budget de 5 € avec alerte par e-mail à 50 % et 100 %.
Les avis sont mis en cache 24 h par le site : quelques dizaines d'appels par mois seulement, normalement dans le quota gratuit mensuel de Google. Vérifier la grille tarifaire actuelle sur developers.google.com/maps/billing-and-pricing (elle évolue).

Étape E — Brancher dans Vercel

  1. vercel.com → projet du site → Settings → Environment Variables.
  2. Ajouter GOOGLE_PLACES_API_KEY = la clé de l'étape D.
  3. Ajouter GOOGLE_PLACE_ID = le Place ID de l'étape C.
  4. Cocher Production (et Preview si besoin) → Save → Redeploy le dernier déploiement.
  5. Test : ouvrir https://www.lescarillons.fr/api/reviews → doit afficher du JSON avec rating et reviews. Une page vide (204) = variables absentes ou pas redéployé ; erreur 502 = clé non restreinte correctement ou API non activée.

Ensuite la section « Avis Google » de l'accueil se remplit toute seule. La note fixe (4,4) dans src/config/site.js ne sert plus que de secours.

4. Autres accès (si disponibles jeudi)

Domaine lescarillons.fr

  1. Demander quel registrar le gère (OVH, Gandi, IONOS…) et qui a les identifiants. Idéalement : être ajouté en contact technique, ou obtenir un accès à la zone DNS.
  2. Dans Vercel → Settings → Domains → ajouter www.lescarillons.fr et lescarillons.fr (Vercel indique alors les enregistrements DNS à créer chez le registrar).
  3. Attention aux e-mails : ne pas modifier les enregistrements MX existants (la messagerie contact@ doit continuer de fonctionner).

Formulaires (Web3Forms)

  1. Aller sur web3forms.com → saisir l'adresse de réception des demandes (ex. contact@lescarillons.fr).
  2. Une clé d'accès (Access Key) arrive par mail à cette adresse : quelqu'un de l'hôtel doit la lire sur place jeudi.
  3. Vercel → Environment Variables → VITE_WEB3FORMS_KEY = cette clé → Redeploy.
  4. Test : envoyer le formulaire de contact du site et vérifier la réception.
